### Adding a record

Take the next number, name the file `NNNN_short_title.md` in lowercase with underscores, and add a row to the index above. Keep the sections the existing records use: context, decision, alternatives considered, consequences. When a decision is replaced, set the old record's status to `superseded by NNNN` rather than deleting it.

Owner decisions that live inside a single ledger entry, such as owner decision 79 in [docs/regression_ledger.md](../regression_ledger.md), stay there. A record here is for a decision that changes how the whole repository is worked on.
