# What e2e/tier1/config_backup_coverage.sh cannot read from a task by itself: the files a shell or
# command task writes, the include of setup/ansible/tasks/config_backup.yaml that backs up a path read
# only while the run goes, and the tasks that write in a home directory or under /etc something that is
# not configuration.
#
# Format: <task file> | <task name> | <what it writes>
#
# <what it writes> is one of:
#   a path, written as the task writes it, which ih_config_files in setup/ansible/group_vars/all.yaml
#     or the literal list of an include of config_backup.yaml must name. A task that writes several
#     files has one line per file.
#   backed up by: <task name>   an include of config_backup.yaml in the same file, before the task
#   not configuration: <reason>
#
# An entry that names no task, or a task that needs no entry, fails, and so does a path no backup names.
