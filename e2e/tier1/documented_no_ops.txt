# Toggles that are deliberately enabled while having no mapping and no install task
# on a given OS family, with the reason. Format: <os_family> <toggle> <reason>
#
# Every line here is a promise that the no-op is intended. The coverage check treats
# anything NOT listed as a defect, because an enabled toggle with nowhere to go means
# the user asks for software, the run reports success, and the software is absent.
# That has happened twice in this project already, with putty and with gradle.
#
# Before adding a line, confirm the software genuinely has no install path on that OS.
# If it does have one, add the mapping instead of an excuse.

# No Linux build published by the vendor.
Debian     chatgpt          OpenAI publishes no Linux desktop build
RedHat     chatgpt          OpenAI publishes no Linux desktop build
Archlinux  chatgpt          OpenAI publishes no Linux desktop build

# Razer Synapse 4 is Windows and macOS only. Linux uses openrazer plus polychromatic.
Debian     synapse          Razer ships Synapse for Windows and macOS only
RedHat     synapse          Razer ships Synapse for Windows and macOS only
Archlinux  synapse          Razer ships Synapse for Windows and macOS only

# Microsoft ships no Linux desktop client for Teams, only the web application.

RedHat     teams            Microsoft ships Teams for web only on Linux
