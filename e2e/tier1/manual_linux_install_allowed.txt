# Names the manual Linux scripts and guides under docs/manual install although no software_mapping
# entry names them, with the reason. Read by e2e/tier1/manual_linux_install.sh.
# Format: <os_family> <name, or pin:<pin name> for a downloaded file> <source> <reason>
#
# <source> is the file under setup/ansible that installs the same name outside the dictionary, and the
# check fails when that file no longer names it. A source of - means only the manual route needs the
# name, and the reason has to say why the playbook does not. A line neither a script nor a guide uses
# any more fails too.
#
# Before adding a line, confirm the playbook really installs it, or really needs no equivalent. If a
# mapping should carry it, add the mapping instead.
